# Бренд-логотипы в карточках WebNetChecker

**Согласовано:** фирменные цвета логотипов (с luminance-guard для тёмных на тёмном), кастомные цели без иконки — буква-аватар; favicon-прокси не делаем (ноль новых сетевых поверхностей, CSP не трогаем — SVG инлайном).

## Шаг 0 — Верификация источника (честно)
Устанавливаем `simple-icons` как **devDependency** и делаем источником истины **локальный npm-пакет** (офлайн, авторитетный) — CDN-эхо в этой сессии были противоречивыми, поэтому CDN не используем вовсе. Скрипт отчётит полный список «покрыто / не покрыто» (ожидаю пробелы среди AI-брендов: OrcaRouter, Requesty, Suno, Runway, Character.AI, Poe, Midjourney и др. — все они изящно уходят в букву-аватар).

## Шаг 1 — Данные (генерация, коммитится)
- `scripts/generate-brand-logos.mjs`: читает хосты сид-каталога (`services.ts`) + ручной маппинг хост→slug (`brand-logo-slugs.ts`, ~79 записей), резолвит через установленный пакет и генерирует `src/lib/config/brand-logos.generated.ts` — **только реально существующие** иконки: `{ title, hex, path }` по хосту.
- Скрипт идемпотентен, запуск `npm run logos` при изменении каталога; непокрытые — в stdout и `.scratch/`.
- Никаких barrel-импортов в рантайме (правило `bundle-barrel-imports`) — сгенерированный файл содержит только использованные иконки.

## Шаг 2 — Компоненты
- `BrandLogo.tsx`: inline SVG `viewBox="0 0 24 24"`, `fill` = фирменный hex; **luminance-guard**: относительная яркость ниже порога (≈0.35) → серебро `--color-silver` (кейс Apple/GitHub: тёмный логотип на тёмном не теряется); `aria-hidden`.
- `LetterAvatar.tsx`: первая буква имени, фон из палитры дашборда по хешу хоста (neon-dim/ok-dim/blocked-dim/steel), тот же размер.
- `resolveBrandLogo(host)` → BrandLogo | LetterAvatar.

## Шаг 3 — Интеграция
- `ServiceCard`: логотип 28px слева от имени.
- `CategorySection`: lucide-иконка категории в заголовке из уже существующего поля `CATEGORIES.icon` — заодно закрывает документированный задел «иконки категорий».
- `ComparisonView`: 16px логотипы в списке сервисов.
- `TerminalView` не трогаем (там статусные эмодзи).

## Шаг 4 — Качество
- Unit-тесты: известный хост → логотип; неизвестный → аватар; luminance-guard (чистый `#000000` → серебро).
- Бандл: сравнить размер первой загрузки до/после в выводе `next build` (цель — рост < ~30KB gzip).
- Гейты: typecheck / lint / test / build / e2e.

## Шаг 5 — Документация
- README: секция «Логотипы» (Simple Icons; атрибуция — логотипы являются торговыми марками соответствующих владельцев, набор иконок CC0), переснятие скриншотов (`node scripts/screenshots.mjs`), свежий hero-скрин.
- Obsidian: `01_Фичи` (+фича, закрыть задел «иконки категорий»), `04_Архитектура` (генерация + luminance-guard), `00_Индекс` (паспорт), `08_Журнал` (запись).
- Коммиты: фича → тесты/гейты → скриншоты/доки.
